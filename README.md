# Build-Lab.dev

A hub for rapid-deployment projects — a home base for spinning up, experimenting with, and shipping small projects fast.

## Status

🏗️ Early setup — nothing built yet. This repo currently holds the project skeleton and docs.

## Purpose

Build-Lab.dev will serve as the central hub for many rapid-deployment experiments. Individual projects may live here or in their own repos, with this hub tying them together.

## Structure

To be defined as the first projects land. Open questions:

- Monorepo (projects live in this repo) vs. hub-and-spoke (separate repos, this site links them)
- Tech stack for the hub site itself
- Deployment target (Vercel is the likely default)
